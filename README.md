# 코비코 프롬프트 키트

코비코(주) ChatGPT 실무 활용 과정(5시간) 실습 프롬프트 워크북을 정리한 페이지입니다.

- PART 01~08 구성, 각 PART는 실습 항목 카드로 구성
- 카드마다 교안 프롬프트 · 이어서 입력(순서대로) · 추가 실습 프롬프트를 각각 복사 가능
- 실습파일이 필요한 PART는 파일명 칩으로 표시
- 강사 시연 항목은 뱃지로 구분되고, 강사 준비사항은 별도 안내 박스로 표시
- 모든 예제·수치·회사명은 교육용 가상 데이터입니다.

GitHub Pages: <https://ernesto923-ctrl.github.io/kovico-prompt-kit/>
